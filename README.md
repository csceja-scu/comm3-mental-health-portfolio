# Mental Health at SCU — COMM 3 Portfolio

A digital storytelling portfolio examining the mental health crisis at Santa Clara University following three student deaths, including two suicides, during fall quarter 2021.

## About

This project was created for COMM 3: Visual Storytelling at Santa Clara University. Through research, an original audio interview, and visual photography, it explores how these events impacted the campus community and the student-led movement that demanded better mental health resources.

**Live site:** [csceja-scu.github.io/comm3-mental-health-portfolio](https://csceja-scu.github.io/comm3-mental-health-portfolio/)

## What's Included

- **Research** — Statistics on mental distress in higher education, sourced from peer-reviewed studies
- **Audio Story** — An interview with former SCU journalism senior lecturer Barbara Kelley
- **Visual Story** — Original photography representing the locations and emotions tied to the events
- **Fact-checked content** — All claims verified against primary sources using journalism standards
